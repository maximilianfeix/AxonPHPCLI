A CI pipeline that fits your PHP project

AxonPHP CLI reads your composer.json, works out which PHP versions and tools you use, and writes the pipeline for your CI service. No config file, no questions.

Get started Try the playground
$composer require --dev maxim/axonphp-cli
  • GitHub Actions
  • GitLab CI
  • Bitbucket Pipelines
  • CircleCI
  • 4CI services
  • 21tools detected
  • 0config files needed
  • 100%line coverage, enforced
How it works

Your composer.json already says what CI should run

Most pipelines start as a copy of the one from the last project, fixed up by hand. AxonPHP derives it from what the project declares.

1 Read

{
    "name": "acme/library",
    "require": {
        "php": "^8.2",
        "ext-intl": "*"
    },
    "require-dev": {
        "phpunit/phpunit": "^12.0",
        "phpstan/phpstan": "^2.0",
        "friendsofphp/php-cs-fixer": "^3.0"
    },
    "extra": {
        "axonphp": {
            "min-coverage": 90,
            "lowest": true
        }
    }
}

The php constraint, every ext-* requirement and the packages you require.

.github/workflows/ci.yml
# Generated by AxonPHP CLI (https://github.com/maximilianfeix/AxonPHPCLI). Edit freely.

name: CI

on:
  push:
    branches: ['main']
  pull_request:

permissions:
  contents: read

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  quality:
    name: Code quality
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v7

      - name: Set up PHP
        uses: shivammathur/setup-php@v2
        with:
          php-version: '8.5'
          extensions: intl
          coverage: none

      - name: Install dependencies
        uses: ramsey/composer-install@v4

      - name: Static analysis (PHPStan)
        run: vendor/bin/phpstan analyse --no-progress

      - name: Code style (PHP-CS-Fixer)
        run: vendor/bin/php-cs-fixer check --diff

  tests:
    name: Tests (PHP ${{ matrix.php }}, ${{ matrix.dependencies }} dependencies)
    runs-on: ubuntu-latest

    strategy:
      fail-fast: false
      matrix:
        php: ['8.2', '8.3', '8.4', '8.5']
        dependencies: ['highest']
        include:
          - php: '8.2'
            dependencies: 'lowest'

    steps:
      - name: Checkout
        uses: actions/checkout@v7

      - name: Set up PHP
        uses: shivammathur/setup-php@v2
        with:
          php-version: ${{ matrix.php }}
          extensions: intl
          coverage: none

      - name: Validate composer.json
        run: composer validate --strict

      - name: Install dependencies
        uses: ramsey/composer-install@v4
        with:
          dependency-versions: ${{ matrix.dependencies }}

      - name: Tests (PHPUnit)
        run: vendor/bin/phpunit

  coverage:
    name: Code coverage
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v7

      - name: Set up PHP
        uses: shivammathur/setup-php@v2
        with:
          php-version: '8.5'
          extensions: intl
          coverage: pcov

      - name: Install dependencies
        uses: ramsey/composer-install@v4

      - name: Code coverage (PHPUnit)
        run: vendor/bin/phpunit --coverage-text --coverage-clover=coverage.xml

      - name: Upload coverage report
        uses: actions/upload-artifact@v7
        with:
          name: coverage
          path: coverage.xml

      - name: Require 90% line coverage
        run: php -r '$m = simplexml_load_file("coverage.xml")->project->metrics; $c = 100 * (int) $m["coveredstatements"] / max(1, (int) $m["statements"]); printf("Line coverage %.2f%%, required 90%%\n", $c); exit((int) ($c < 90));'

# Generated by AxonPHP CLI (https://github.com/maximilianfeix/AxonPHPCLI). Edit freely.

stages:
  - quality
  - test

workflow:
  rules:
    - if: $CI_PIPELINE_SOURCE == 'merge_request_event'
    - if: $CI_COMMIT_BRANCH && $CI_OPEN_MERGE_REQUESTS
      when: never
    - if: $CI_COMMIT_TAG
    - if: $CI_COMMIT_BRANCH == 'main'

variables:
  COMPOSER_ALLOW_SUPERUSER: '1'
  COMPOSER_NO_INTERACTION: '1'
  COMPOSER_CACHE_DIR: $CI_PROJECT_DIR/.composer-cache

default:
  cache:
    key:
      files:
        - composer.lock
        - composer.json
    paths:
      - .composer-cache/
  before_script:
    - curl -sSLf -o /usr/local/bin/install-php-extensions https://github.com/mlocati/docker-php-extension-installer/releases/latest/download/install-php-extensions
    - chmod +x /usr/local/bin/install-php-extensions
    - install-php-extensions @composer zip intl
    - composer install --prefer-dist --no-progress

quality:
  stage: quality
  image: php:8.5-cli
  script:
    - vendor/bin/phpstan analyse --no-progress
    - vendor/bin/php-cs-fixer check --diff

tests:
  stage: test
  image: php:${PHP_VERSION}-cli
  parallel:
    matrix:
      - PHP_VERSION: ['8.2', '8.3', '8.4', '8.5']
  script:
    - composer validate --strict
    - vendor/bin/phpunit

tests:lowest:
  stage: test
  image: php:8.2-cli
  before_script:
    - curl -sSLf -o /usr/local/bin/install-php-extensions https://github.com/mlocati/docker-php-extension-installer/releases/latest/download/install-php-extensions
    - chmod +x /usr/local/bin/install-php-extensions
    - install-php-extensions @composer zip intl
    - composer update --prefer-lowest --prefer-stable --prefer-dist --no-progress
  script:
    - vendor/bin/phpunit

coverage:
  stage: test
  image: php:8.5-cli
  script:
    - install-php-extensions pcov
    - vendor/bin/phpunit --coverage-text --coverage-clover=coverage.xml
    - php -r '$m = simplexml_load_file("coverage.xml")->project->metrics; $c = 100 * (int) $m["coveredstatements"] / max(1, (int) $m["statements"]); printf("Line coverage %.2f%%, required 90%%\n", $c); exit((int) ($c < 90));'
  coverage: '/^\s*(?:Lines|Total):\s*\d+\.\d+\s*%/'
  artifacts:
    when: always
    paths:
      - coverage.xml

Features

Everything a good pipeline has, none of the copy and paste

A matrix that follows your constraint

"php": "^8.2" becomes a test matrix of 8.2, 8.3, 8.4 and 8.5. Narrow the constraint and the matrix narrows with it, on every provider.

"php": "^8.2"→8.28.38.48.5

The tools you already use

21 tools across tests, static analysis, code style and dependency checks. Installed means it runs.

A pipeline that stays in sync

ci:check fails when the committed file drifts from the project. ci:update brings it back.

Coverage with a floor

A coverage job on the newest PHP version, and a minimum the job has to reach.

Careful defaults

Dependency caching, least-privilege permissions, cancelled superseded runs and no duplicate runs for pull requests.

Plain YAML that belongs to you

No plugin, no runtime, no lock-in. The result is one readable file for your CI service. Nothing is overwritten unless you confirm it, and --dry-run prints the result first.

Commands

Five commands, one job each

ci:init

Generates the pipeline. Leave the provider out and it asks which one you use.

$ axonphp ci:init gitlab
$ axonphp ci:init github --dry-run
$ axonphp ci:init circleci --min-coverage 90

ci:check

Fails when a committed pipeline no longer matches the project. Made for CI.

$ axonphp ci:check
$ axonphp ci:check --format github
$ axonphp ci:check --format json

ci:update

Rewrites the pipelines that are out of date and leaves the others alone.

$ axonphp ci:update
$ axonphp ci:update --dry-run
$ axonphp ci:update gitlab

inspect

Shows what was detected without writing anything. JSON output for scripts.

$ axonphp inspect
$ axonphp inspect --format json | jq '.php.versions'

tools

Lists every tool and provider the installed version supports.

$ axonphp tools
$ axonphp tools --format json
Configuration

Optional, and in the file you already have

AxonPHP needs no configuration. When you want choices to stick, put them under extra.axonphp in composer.json. Command line options still win.

  • php pins the versions to test.
  • branches lists the branches whose pushes trigger the pipeline.
  • coverage, lowest and audit switch on the extra jobs.
  • min-coverage is the line coverage the coverage job has to reach.
composer.json
{
  "extra": {
    "axonphp": {
      "branches": ["main", "develop"],
      "min-coverage": 90,
      "lowest": true,
      "audit": true
    }
  }
}
Install

Three commands to your first green run

Requires PHP 8.2 or newer. Install it as a development dependency of the project you want a pipeline for.

  1. Add the repository

    $composer config repositories.axonphp vcs https://github.com/maximilianfeix/AxonPHPCLI

  2. Require the package

    $composer require --dev maxim/axonphp-cli

  3. Generate your pipeline

    $vendor/bin/axonphp ci:init

The package is not on Packagist yet, which is why the repository is added first. A PHAR is attached to every release.
